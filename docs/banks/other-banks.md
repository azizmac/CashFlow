# Другие банки РФ

Общее правило: **API у всех банков — только для бизнеса (ИП/ЮЛ); физлицам — файлы выписок**, пока не заработал Open API ЦБ (см. [cbr-open-api.md](cbr-open-api.md)). Официальных MCP-серверов у этих банков нет (проверено поиском GitHub 2026-09-04 — только самодельные обёртки у отдельных авторов, не поддерживаются банками).

## Альфа-Банк

- **Alfa API** (бизнес): <https://developers.alfabank.ru/products/alfa-api> — REST + OAuth2 (client_credentials), счета, выписки, платежи. Для подключения: договор РКО + выпуск ключей в интернет-банке.
- Физлица: официального API нет → выписка из «Альфа-Мобайл» (PDF/Excel) — парсер пока не написан, кандидат в `Connectors.Statements`.
- Инвестиции («Альфа-Инвестиции»): публичного API нет.
- Коннектор `AlfaBusinessConnector`: делать по образцу `TBankBusinessConnector` (тот же паттерн: GET счетов → GET выписки → маппинг в External*). Endpoint'ы и формат — по docs на developers.alfabank.ru (уточнить на боевом ключе перед коммитом примеров).

## ВТБ

- Бизнес: API интернет-клиента ВТБ (доступ по заявлению, REST; актуальный портал документаций уточнить у банка — публичной единой точки как у Т/Сбера нет). ⚠️ URL не проверял — не ссылаться в UI без подтверждения.
- Физлица: только выписки (PDF/Excel из ВТБ-Онлайн). В роадмапе парсеров — `VtbPdfStatementParser`.
- ВТБ Инвестиции: публичного API нет.
- MCP: официального нет; в GitHub-поиске вменяемых обёрток не найдено.

## Прочие (кратко)

| Банк | Бизнес-API | Физлица-канал | MCP |
|---|---|---|---|
| ПСБ | есть (РКО API, по заявлению) | PDF-выписка | нет |
| Газпромбанк | есть (ГПБ Business API) | PDF/Excel | нет |
| МКБ | есть | PDF | нет |
| Совкомбанк | есть | HTML/PDF выписка (парсер — кандидат) | нет |
| МТС Банк, Точка, Модульбанк | есть (у Точки/Модуля — REST-выписки с токеном, популярны у ИП) | выписки | нет |
| Райффайзенбанк | есть (Raisely/R-Check и API РКО) | PDF | нет |

Точка/Модульбанк — самые «API-дружелюбные» для микробизнеса: если у пользователя ИП там, имеет приоритет как следующий коннектор после Альфы (детали эндпоинтов — в ЛК банка, публичная документация неполная ⚠️).

## Тактика для CashFlow

1. Не писать парсеры «на всякий случай» — под каждое подключение по запросу пользователя (формат выписок меняется; см. опыт с Сбер PDF).
2. Всех, у кого нет API-доступа, вести в profile «физлицо» через импорт выписок.
3. С приходом Open API ЦБ эти различия каналов для физлиц исчезнут — один коннектор на все банки-участники.
